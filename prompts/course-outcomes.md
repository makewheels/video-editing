# 课程成果展示：可复用剪辑主提示词

适用：用户说“12节课学到什么”“毕业考试”“把这批学习成果剪出来”。课次数是输入参数，不是必须凑齐的动作数量。本批历史要求曾为10节课，不能直接把旧片改称12节课。

```text
你的任务是把一批学员素材整理为可信、易看懂的课程成果展示，并保存可以复现的工程。先读取本批最新反馈、专业术语表与风格配置，自行完成常规判断，不要求用户逐段指定剪法。

输入：素材批次ID、原素材、参考片、已知课次数/学员背景、用户最新要求、历史方案、交付权限。缺少课次数就不写“12节”；没有第一课画面就不做虚构前后对比。

A. 先建教学项目表，之后才做时间线。
逐条审看原素材，结合连续画面、教练讲话和参考片文字，记录：项目ID、教学目的、显示名称、来源起止、完整过程、清晰度、重复关系、疑点。
泳姿只是分类之一。无泳镜适应、踩水、入水、探底等可能各自是教学项目。相同泳姿不必然代表相同教学目的；相同项目多个镜头不自动成为多个项目。
同项目重复优先选最清晰完整的一条；只有教学差异确实存在才保留补充镜头。例：原12/13“深水探底”归一个项目，一个编号。无法证明独立教学目的就不人为拆分。

B. 名称来自有依据的术语映射。
参考术语表中的“摇橹式踩水”“不带泳镜游泳”等候选名称，不能见到水中站立就自动标踩水，也不能仅见没戴泳镜就断言它是独立考核项目。先结合教练口述/项目清单及连续示范确认。不确定时留下具体待核对项，不编造名称、不硬凑覆盖。

C. 组织成片。
选择最清楚的真实成果作开头，随后按学习或考核逻辑分组展示。项目编号在去重和排序完成后生成，同一项目跨镜头不换号。
标题只显示一行“01 项目名称”，上方安全区域，优先白字细描边；背景复杂时试轻底板。底板不是永久强制项，不能数字单独一块、名称再一块。
作品结构可选：简洁项目展示，或带真实前后对比的成果故事。没有获准的宣传结尾时不擅自加联系方式、地点、口号。

D. 调用独立风格参数。
“每项目3—5秒”仅作为精简展示候选；先保证完整动作/必要结果可见，不机械截掉过程。保留全覆盖的完整成果版；用户另需获客短版时从同批另出一个用途明确的版本，不能用短版冒充全覆盖。
动画在项目和镜头两个层级安排，短进出动画只在关键动作之外，不能为了炫技改变动作、制造黑帧或频繁重复项目标题。
音频继承本批规则：当前本批教练原声、无配乐。其他作品如果选择轻音乐模板，先确认音乐可用来源及是否要保留讲话，不能覆盖旧要求。

E. 输出与自检。
先输出教学项目表、去重理由、待确认项、选用风格，再生成中立结构化方案。若现有渲染协议只能按片段编号，明确实现项目分组编号后再渲染，禁止偷偷用片段号代替。
检查名称与画面、序号连续、同项目不重号、每个必需项目完整可见、文字不挡人、音画同步。技术检查和语义审片分别留证据。
每个版本都归档到本批OSS目录，保存成片、方案、报告、反馈、提示词版本、父版本；需要手机观看时另走点播交付并校验。
```

## 教学项目中间产物与当前渲染映射

```json
{
  "lesson_count": 12,
  "video_type": "course_outcomes",
  "teaching_items": [
    {
      "item_id": "skill-01",
      "display_name": "深水探底",
      "display_number": 1,
      "clip_ids": ["candidate-a", "candidate-b"],
      "selected_clip_ids": ["candidate-a"],
      "dedup_reason": "相同教学目的，选择完整且清晰的一条",
      "evidence": [],
      "status": "needs_visual_confirmation"
    }
  ],
  "style": {"numbering_unit": "teaching_item", "title_layout": "one_line"}
}
```

该例用于说明分组关系，不能直接交给渲染CLI。空evidence不能进入最终确认方案。2026-09-19已实现`Output.number_contents=true`：先把教学项目映射为`contents`，同一项目各镜头引用同一`content_id`，然后按首次出场顺序编号；搭配`caption_style=plain`保持序号和名称同一行。旧`number_clips`只用于旧方案重现。手机智能模式采用两轮抽帧辅助判断，不代表已完成逐帧或音频语义审片。
