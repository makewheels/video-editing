## P0：服务器与执行器验证

范围：先选已授权的服务器，再验证现有订阅路线。不能假定模型 API 可用，也不先开付费 GPU。

交付：环境报告、独立任务包、非交互最小任务、视觉输入能力证据、额度耗尽/登录失效/取消的行为记录。

退出条件：服务器能从干净 checkout 跑 `doctor`、`demo`、测试；独立任务包能生成合规方案；重启后不依赖原会话。暂时没有服务器或账号授权时，继续做下面不依赖它们的工作，不伪造成功。

## P1：真实素材理解与审片闭环

范围：接入代理视频、连续区间采样、可选场景检测/ASR/OCR；视觉模型根据画面生成内容清单。先用游泳样片，不把动作名称写死进通用代码。

交付：所有素材的角色清单、独有内容覆盖表、候选区间、置信与不确定原因、字幕安全区域、两版以内的可比较样片、语义/观感审核结果。

退出条件：出发不是泳姿；每个已确认独有内容都有完整动作区间；语音错位不会导致字幕错标；观众能看清动作；没有音乐时明确静音。参考片默认不进入成片。目标时长不足时显式处理冲突。

下一位编码 agent 可以直接从 `inspect` 的连续预览与素材索引做起，再扩展识别 adapter；不必重建渲染器。

## P2：持久任务与点播链路

范围：实现 `docs/execution-design.md` 的工程、版本、状态机与 worker；点播接口以本机代码为线索重新验证。

交付：可重试任务、幂等键、租约/心跳、fencing、取消、阶段日志；素材上传和私有下载 adapter；验证后发布成片。

退出条件：重复提交不产生重复视频，worker 崩溃能恢复，旧 worker 不能覆盖新任务结果，临时清理不伤原片或可恢复工程，成片不会意外公开。
