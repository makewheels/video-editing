# 游泳账号增长分析与执行建议

分析版本：2026-09-19阶段报告。对象：大庆游泳刘教练（收徒），用户提供账号yes1_33_5119_073。目标：本地招生、有效涨粉及提高高传播作品出现概率。

## 结论先行

保留真实学员成果作为信任证明，增加“观众看完能理解一个问题”的教学栏目，再用阶段进步和本地答疑承接咨询。现有结业展示已有高传播样本，不应因最近几条表现一般就推倒重来。接下来要验证的是：观众除了看见学员会游，还能否理解教练怎么教、自己适不适合来学。

AI剪辑优先修正内容结构：识别教学项目→术语确认→合并重复→按项目编号→选择风格。特效排在后面。当前v6的深水探底重复编号和两块字幕问题仍待重剪，不能当作成功模板。

## 可检验的高传播方向

1. 成果证明：用学员真实可见的结果制造期待。将“又毕业一位”改成更具体的问题，例如“这次结业，哪些项目是单独考的？”；不虚构学员基础和课次。
2. 单问题教学：将“漂浮练习”转换成“看漂浮时，先看哪一个点？”由教练给出要点；字幕和镜头为同一个问题服务。
3. 对比与纠正：只有对照素材真实且同一条件可比时使用。错误示范由教练决定，避免让学员为了内容做危险动作。
4. 连载：固定栏目名和问题粒度，提高观众理解下一条还能获得什么的能力。可用“教练只改一个点”“第N课实录”等，不承诺统一学会时间。
5. 轻松互动：笑点来自教练解释方式或常见误会，不来自羞辱学员。搞笑属于小比例实验，不急于整号转型。

以上是由样本推导的实验假设，不是算法规律或流量保证。

## 第一轮10条内容组合（建议实验，不是平台最优配比）

- 4条单问题教学：同一问题准备两种开头表达，每次只变一个因素。
- 3条真实成果：其中1条保留完整项目清单，另外2条各突出一个不同学习结果；同素材衍生片必须用途明确。
- 2条阶段进步／报名答疑：分别回答“目前学到哪”和“像我这样能怎么开始”。
- 1条日常或轻喜剧：检查是否带来目标人群互动，而不是只看播放。

先按正常发布节奏试10条，不建议一次性连发、删除原片、买粉或先用投流掩盖内容问题。无需固定每日几条，以拍摄质量和教练时间为约束。

## 招生与涨粉的评价方法

内容分工：教学获取潜在学习者关注；成果降低对教学能力的不确定；阶段故事增加代入；本地答疑帮助报名决策。获客版可在用户授权范围内加入轻量本地咨询引导，不能给所有教学样片强加联系方式。

每条记录内容类型、开头、片长、提示词版本、发布时间，7天后记录后台可得的观看/停留、关注、有效本地咨询、试听和报名。建议计算“每千次后台播放新增关注”和“每千次后台播放有效本地咨询”，分母必须同平台同时间窗口；公开累计计数不能混入。报名只计实际发生，不将留言等同转化。

先建立自己的中位数基线，再看同类型至少数条的表现。不因一条高播放就改全号，也不因刚发布一小时数字小就判失败。每轮最多调整开头、信息结构、时长等一个主要变量。

## 自动剪辑的现实路径

见 `filming-and-automation.md`。教练只提供“项目口述卡＋完整动作＋必要补充角度＋一句解释”；AI负责素材盘点、类型匹配、去重、标题编号、渲染、校验、归档和交付。

已可执行：本地方案渲染、技术校验、点播上传和OSS归档。仍需实现：教学项目分组编号、一行标题新样式、稳定素材理解接口和无人值守调度。此次交付的是有证据的账号研究与可执行提示词，不把文档当成全自动服务已经上线。
