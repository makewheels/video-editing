# 从历史剪映工程学习剪法

记录日期：2026-10-04。本文记录用户的长期目标和验收方式；目前尚未完成剪映历史工程的内容分析。

## 用户目标

以后用户只需上传新视频，并补充本次主题或少量特殊要求，剪辑系统就能参考用户过去亲自完成的作品，自主选择镜头、安排节奏、处理文字和声音、生成可审看的成片。用户不应每次重新讲一遍自己的剪辑思路。收到修改反馈后，下一版保留旧版，并把明确可复用的经验更新到项目中。

历史剪映工程是学习依据，不是新片的素材库。新片只使用本次授权的素材；历史作品中的学员画面、声音和个人信息不得自动移入新片。

## 先分视频类型，再选对应剪法

先从用户亲自完成的代表工程归纳视频类型及各自的剪法。项目已有的[内容类型候选](../prompts/content-types.md)列出课程成果、阶段进步、单项教学、日常训练等工作分类；它们来自有限的公开作品样本，还不是对全部剪映工程的最终分类。误区纠正、轻喜剧和报名答疑目前是实验方向，不能当作已学到的历史风格。

收到新素材后，先看本次要表达的目的、素材实际内容和用户的简短要求，确定主要类型与理由，再调用该类型已经确认的结构和风格。分类不能只看文件名、镜头数量或是否在泳池拍摄；同样的游泳画面可能用于成果展示，也可能用于单项教学。若素材跨两类，明确主目标及可借用的次要元素；若现有类型都不合适，建立待验证的新类型，不硬套旧模板。只有类型或教学目的确实影响成片且无法从素材判断时，才向用户问一个关键问题。

每种类型分别保存：适用条件、代表作品证据、内容结构、镜头取舍、节奏、字幕、声音、转场、可变参数与禁用条件。共享的技术约束可复用，但某一条旧片的音乐、字幕或秒数不能自动升级成全类型规则。

## 怎样才算学到了剪法

仅有云草稿名称、时长、文件清单、封面或时间线元数据，不足以判断为什么选某个镜头。每种要复用的作品类型，至少选取代表工程，结合以下证据分析：

1. 完整观看成片或工程预览，记录开头、主体、结尾、画幅、字幕、声音和整体节奏。
2. 阅读时间线，记录源片取用区间、镜头顺序、字幕时点、音轨、转场和效果。
3. 查看有争议的原素材前后文，弄清保留与舍弃镜头的理由；不必为此下载全部历史原片。
4. 将观察分为“画面可证实”“时间线可证实”“推断”“用户确认”四种，注明适用的视频类型和例外。用户的最新明确反馈优先于旧工程。

只读调查已经确认剪映云草稿索引可访问，也看过少量封面；已取得部分公开成片并抽帧，但尚未完成逐段听看，也未取得代表工程的时间线和必要原素材内容。当前不能声称已学会用户的剪辑手法。

## 已发布成片提供第一层证据

抖音已发布作品可以先判断内容类型、开头主题、画面组织和可见字幕，再据此选择要核对的剪映工程。2026-10-04 重新获取并抽看了[账号样本报告](research/account-analysis-20260919.md)中的五条本账号作品，每条取 24 帧：两条课程成果片按多个教学项目接续展示，第四节课记录与漂浮练习保留较长的连续动作画面，晨游日常依次呈现出门、到水边、下水。这支持按类型分别学习，不支持把某一种剪法套给全部新素材。

上述观察是画面抽样，不是逐帧审片或完整听音；尚不能确定精确剪口、音乐与原声处理，也不能从成片反推所有被舍弃的原素材。发布版用于选样与提出候选规则，剪映时间线及必要原素材用于确认这些规则。

## 交付物

- **Markdown 风格手册**：按视频类型解释选镜头、内容排序、节奏、字幕、声音、转场及不适用情形。每条规则标明来源、确认程度；私人作品的详细引用留在私有记录中，不提交公开 Git。
- **结构化风格配置与示例方案**：将确认过且可参数化的规则放进现有方案协议、提示词或配置；提供不含私人素材的最小示例。Markdown 负责说明，结构化文件负责让剪辑流程稳定执行。
- **代表作对照记录**：在私有存储中保存工程、成片、必要素材区间的对应关系和审片结论；不把原视频、音轨、云端凭据、学员信息或私人路径提交 Git。
- **新素材验收**：用未参与归纳的新素材剪出一版，完整观看并与手册逐项核对；记录用户反馈，再修订规则。技术渲染通过不能代替用户对剪法的认可。

## 执行顺序与存储

先挑少量覆盖不同类型的代表作品，逐个分析，再扩大样本。优先读取云端已有的工程与预览；确需下载时只取当前工程必要文件，先确认磁盘和云端剩余额度，保留原件、不批量搬运。iCloud 或其他网盘可作经确认的样本中转与私有备份，不能替代本项目既有的私有素材归档和版本记录，也不是服务端运行的前提。

完成历史学习后，新片流程为：盘点用户上传素材 → 判断视频类型与本次重点 → 选择该类型已确认的剪法 → 生成方案 → 渲染和审片 → 交付新版 → 根据反馈更新对应类型的规则。若新素材缺少历史剪法所需的镜头或声音，明确说明并调整方案，不伪造内容。
