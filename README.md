# Video Editing

面向手机使用的个人 AI 视频剪辑平台。当前仅保存需求讨论和调研结论，尚未实现或部署。

## 已确认的方向

- 手机浏览器上传素材、描述要求、查看进度、预览和下载成片。
- 服务端执行剪辑，不依赖用户的 Mac 或电脑保持开机。
- 第一阶段自动出片，用户下载到手机后手动发布抖音；第二阶段支持对话修改和版本回退。
- 记录可持续积累的剪辑规则和个人偏好。
- 优先验证并改造开源项目，不预设从头编写编辑器或渲染引擎。
- 用户目前只有 Codex 订阅，没有模型 API Key；不得默认采用需要额外模型 API 付费的方案。
- 本项目位于公网 GitHub 的 makewheels 账号下，与公司 GitHub 无关。

## 两个平台、两个仓库

| 平台 | 职责 |
| --- | --- |
| [video-2022](https://github.com/makewheels/video-2022) | 视频点播平台：上传、存储、转码、播放、下载 |
| video-editing（本仓库） | 剪辑平台：手机页面、工程、任务、素材关联、偏好、剪辑方案、对话修改、执行程序及部署配置 |

剪辑工程和偏好归剪辑平台管理。点播平台只管理视频，不承担剪辑业务。原始素材和成片不提交到 Git。
