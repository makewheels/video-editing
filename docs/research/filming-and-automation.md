# 教练拍摄任务与自动剪辑闭环

## 一次课的最小素材包

本建议是拍摄生产规范，不是已完成的系统功能。由教练在正常安全教学安排内拍摄，不为短视频加做危险项目。

- 口述卡：今天课次、项目名称、这段想展示什么、可使用的姓名/称呼；拍摄前说一句即可，后期不必进入成片。
- 全景：完整动作开始至结束，关键部位可见，首尾各留约1秒余量。一次完整示范优先于多段碎片。
- 补充角度：仅在确实需要解释教学差异时拍，不重复堆同样镜头。
- 一句教练解释：说一个具体要点，避开多人同时说话；不要求演讲式长口播。
- 阶段记录：有真实第一课与当前课素材时保留对比；没有就从今天开始积累。
- 结尾结果：实际做到什么、还需练什么。避免统一“天才”“包会”的空泛评价。

## 两条进入路径

A 已有素材：AI盘点→教学项目表→类型/风格匹配→术语确认→去重与排序→方案→渲染→检查→OSS归档→点播交付。
B 缺少素材：AI从选题生成拍摄清单→教练按正常教学拍摄→上传同批素材→进入A。

理想状态是剪辑步骤不需要用户逐剪口操作；疑似错名、缺少关键镜头或专业结论不确定时，只问最小必要问题，不能靠猜测假装全自动。

## 当前能力与缺口

已实现：结构化计划校验、字幕/转场/音频渲染、版本成片、点播交付、专用OSS归档脚本。
仍待实现：教学项目分组编号、一行标题新布局、可复用素材理解与类型选择接口、持久任务队列、失败重试及无人值守服务。当前靠执行助手串联，不是已部署的自动剪辑平台。

## 每轮调教记录

批次ID；输入素材散列；提示词版本；目标类型；风格参数；术语新增/修正；项目合并/拆分理由；用户反馈；预期改变；实际结果；证据范围；下一轮动作。

阶段结束先写GitHub进度，再把本轮提示词/反馈快照存入该批OSS的时间目录。成片一经生成就归档新版本，不能只留点播链接。
