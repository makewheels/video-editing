# 内容类型与独立剪辑提示词

当前根据本账号11条同作者公开作品标题/时长，建立4类工作模板；这是样本分类，不是对全账号固定类型总数的最终判断。后续实际画面审查可修正归类。另加3类增长实验，不能说账号已经在做。

通用前置：先读本批素材、反馈、术语表；教学项目优先于镜头；所有判断给来源区间；没有素材就提出拍摄清单。声音、时长、底板和动画是独立风格参数，不写死在账号层。每轮记录提示词版本并归档OSS。

## A 课程成果／结业考试（样本7条）

使用 `course-outcomes.md`。把完整教学项目清单转成稳定编号，每项目一个名称。可以同时输出完整考核版与获客精简版，但必须明确两者覆盖差异，不能让短版冒充完整考核。

## B 学习过程／阶段进步（样本1条）

```text
从同一学员、同一教学目标的素材中找可比较的阶段。先标明日期/课次的证据，没有对照素材就做“本节练习记录”，不伪造“从不会到会”。
结构：可见问题或本节目标→教练关键提示→练习变化→本次做到哪一步。只讨论本次有画面支持的变化，不写保证几节课学会。
优先保留教练一句有用的原声，删除空等候和重复口令。画面与口述不同步时重新组织说明，不让字幕错误对应动作。
输出素材证据表、阶段关系、字幕与剪辑方案；需要补拍时列最少镜头。
```

## C 单项技术／教学示范（样本1条；蛙泳/划水教程属于此类细分）

```text
每条只回答一个具体问题，例如手腿配合或一个划水环节。先辨认教学目标，按“问题画面→可见关键点→正确示范→一次完整复看”组织。
只有教练提供或可核实的技术说明才能作为教学结论；模型不能自行编造标准动作。缺少错误或正确示范时，使用现有部分并说明补拍需求，不拼接成虚假对比。
术语稳定，字幕一次强调一个点。镜头长度以看清动作和讲完一句话为准，3—5秒不是机械截断规则。慢放只用于局部复看，正常速度的完整示范必须保留。
输出讲解所需原声/字幕、正常速度区间和复看区间，以及哪些技术结论需要教练确认。
```

## D 日常／训练vlog（样本2条）

```text
先找真实的小事件、目标或变化，不能只按拍摄先后堆镜头。结构：今天做什么→一个过程细节→结果/感受。
有用的环境声优先保留，音乐按已授权素材选择。不要把普通训练包装成教学承诺；地点、课次和成果只用已知事实。
每条至少保留一个能理解教练工作或学员感受的细节。与招生无关的日常作为人格补充，不能替代主体教学内容。
```

## E 误区纠正（增长实验，未证明是本账号现有固定栏目）

```text
由教练选择一个高频问题，提供可安全示范的对比。开头直接展示问题，随后一条解释和一个可见修正点，最后正常速度复看。标题说清具体疑问，不用夸张保证。
若错误示范会带来风险，改为岸上示意、图示或教练解释，不让学员故意做危险动作。观众留言可作为选题，不自动视为专业诊断。
```

## F 轻喜剧＋教学反差（增长实验）

```text
使用真实且获准的轻松互动或教练自我演示，避免嘲笑学员、身体评价和虚构尴尬。结构：常见误会→反差→一个有用解释。搞笑必须服务内容理解或教练亲和力，不改变技术事实。
没有可用素材就输出对话和镜头建议，由教练决定是否拍摄；不能伪造人物说过的话。
```

## G 本地报名决策／答疑（增长实验）

```text
每条解决一个报名顾虑，例如怕水、成人零基础、课程安排或场馆体验。问题→真实课堂/设施证据→已确认的信息→一个轻量下一步。
价格、地址、资质、保证、课次数均需用户或真实资料提供。只在已授权营销版本加入本地咨询引导，不把联系方式或口号强塞进教学样片。
不把点赞或评论推断为报名，效果按有效本地咨询、试听和实际报名另行记录。
```
